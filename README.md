# Arkanoid3D
Arkanoid3D is a 3D version of the classic Arkanoid game.

## Introduction
This is Part of a Asssignment for the GamesEngines Class of the Software Engineering Degree at the University of Heilbronn.

## Features
- 3D Graphics
- Random Level Generation
- Power-Ups
- Score Tracking
- Beutiful Soundtrack and Assets

## Installation
To install and run Arkanoid3D locally, follow these steps: <br>
Download the [Release](https://github.com/Drauboss/Arkanoid3D/releases/download/v1.0.0/Arkanoid3D_V1.zip), extract the files and run the Arkanoid3D.exe file.

## Usage
To play the game, use the following controls:

- Left Arrow: Move left
- Right Arrow: Move right
- Spacebar: Launch the ball

## Development
To develop Arkanoid3D, follow these steps:
